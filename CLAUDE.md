# Bairro Alerta

## What it is

Academic project (UNIVALI, ADS): an Expo/React Native app where residents report neighborhood
infrastructure problems (potholes, lighting, debris, sidewalks, flooding) and the residents'
association moderates them. The pilot runs as the web build on Firebase Hosting, project
`bairro-alerta-9016` (https://bairro-alerta-9016.web.app). Everything stays on the Firebase free plan.
Decided 2026-11-07: the pilot moves to an Android APK built with EAS (`eas.json` profile `preview`),
with the web build kept as the iPhone fallback. See `docs/guia-piloto.md` Section 3.

## Terminology

Code, UI, commits and docs are in Portuguese. Key words: ocorrência (a report), apoio (a resident
"+1" on a report), semelhantes (similar reports within 50 m), moderação (association hides or
changes status), avisos (notifications), status `aberta | encaminhada | em_andamento | resolvida`.

## Layout

- `src/app/`: Expo Router routes only (`entrar`, `cadastro`, `(app)/index|nova|avisos|ocorrencia`).
  They render screens from `src/telas/`.
- `src/telas/`: screens. `src/componentes/`: shared UI (`ui.tsx`, `CartaoOcorrencia`, `Mapa` / `Mapa.web`).
- `src/domain/`: pure rules (validation, filters, similar reports, moderation, notifications).
- `src/servicos/`: ocorrências service, EXIF stripping, location.
- `src/plataforma/`: Firebase wiring (excluded from coverage). `src/dados/memoria.ts`: in-memory repo for tests.
- `src/contexto/ambiente.tsx`: dependency injection; root layout builds the real environment.
- `firestore.rules` + `regras/`: security rules and their emulator tests.
- `e2e/`: Playwright specs on the web build. `scripts/`: e2e, rules, emulator, smoke-test runners.

## Running and testing

- Node 22. Copy `.env.example` to `.env`; `EXPO_PUBLIC_USE_EMULATORS=1` for dev.
- Before calling work done: `npm run lint`, `npm run typecheck` (checks app, `regras` and `e2e`), `npm test`
  (coverage threshold 80% global).
- `npm run test:regras` needs Java 17+ (Firebase Emulator).
- End to end the way a user would: `npm run e2e` builds web, starts emulators, runs Playwright on a
  Pixel 7 profile, and refreshes the screenshots in `docs/capturas/`.
- `npm run fumaca` is a smoke test against production (creates and deletes a test account).

## Conventions

- Strict TDD visible in history: a `test: ... (vermelho)` commit, then `feat: ... (verde)`. Commit
  subjects in Portuguese, conventional prefix, optional story number (`feat(#4): ...`).
- Photos go to the Firestore `fotos` collection (max 1024 px, JPEG 60%, no EXIF, 700 KB rule limit),
  not Cloud Storage, because Storage needs the paid plan.
- Native map: MapLibre (`@maplibre/maplibre-react-native`) with free OpenFreeMap styles, no API key; keep the
  OSM attribution visible. The web build shows the illustrated map instead (`Mapa.web.tsx`).
- No personal data on reports; login errors stay generic.
- Ask before `npm run publicar` (deploys rules and Hosting to the real project) or `npm run fumaca`.
