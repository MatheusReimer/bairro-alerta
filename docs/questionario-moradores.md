# Questionário com moradores (Google Forms)

Texto pronto para colar no Google Forms. As perguntas são as do Quadro 3 do relatório da Etapa 1.

**Configuração do formulário**

- Configurações > Respostas: **não** coletar e-mails e **não** limitar a uma resposta (exigiria login no Google).
- Todas as perguntas obrigatórias, menos a 6.
- Tempo no ar: uma semana. Meta: pelo menos 30 respostas.
- Divulgação: grupo de mensagens dos moradores e, se a associação concordar, os canais dela.
- Ao fechar: Respostas > ícone do Planilhas, para exportar. Guarde a planilha para o relatório (Seção 4.1.1 e 5.1.3).

## Título

Problemas de infraestrutura no bairro: sua opinião

## Descrição

Olá! Somos estudantes de Análise e Desenvolvimento de Sistemas da UNIVALI e estamos criando o **Bairro Alerta**,
um aplicativo para os moradores registrarem e acompanharem problemas do bairro, como buracos, postes apagados,
entulho, calçadas quebradas e alagamentos. A associação de moradores organiza os registros e encaminha à prefeitura.

Este questionário leva cerca de **2 minutos**. Ele é **anônimo**: não pedimos nome, e-mail nem endereço. As respostas
serão usadas apenas neste trabalho acadêmico, de forma agrupada, conforme a Lei Geral de Proteção de Dados
(Lei nº 13.709/2018). Ao responder, você concorda com esse uso. Obrigado por ajudar o bairro!

Grupo 94: Ana Clara, Laura Welter Góes, Matheus Henrique Reimer e Brayan Silveira.

## Perguntas

**1. Você notou algum destes problemas no bairro nos últimos seis meses?** *(caixas de seleção)*

- [ ] Buracos na rua
- [ ] Iluminação pública apagada ou com defeito
- [ ] Entulho ou lixo descartado em local errado
- [ ] Calçadas quebradas ou obstruídas
- [ ] Bocas de lobo entupidas ou alagamentos
- [ ] Outros: ______
- [ ] Não notei nenhum problema

**2. O que você fez na última vez em que viu um problema desses?** *(múltipla escolha)*

- ( ) Nada
- ( ) Comentei no grupo de mensagens do bairro
- ( ) Entrei em contato com a prefeitura (156, site ou aplicativo)
- ( ) Procurei a associação de moradores

**3. Se você fez uma solicitação formal (prefeitura ou associação), recebeu retorno?** *(múltipla escolha)*

- ( ) Sim
- ( ) Não
- ( ) Não fiz solicitação formal

**4. Você costuma saber se outra pessoa já relatou o mesmo problema?** *(múltipla escolha)*

- ( ) Sim
- ( ) Não

**5. De 1 a 5, quanto você usaria um aplicativo para registrar e acompanhar esses problemas?** *(escala linear 1 a 5)*

1 = Não usaria · 5 = Usaria com certeza

**6. Algo deixaria você inseguro ao usar um aplicativo assim?** *(caixas de seleção, opcional)*

- [ ] Meu nome aparecer para os vizinhos
- [ ] Mostrar onde eu moro ou onde eu estava
- [ ] O que seria feito com meus dados pessoais
- [ ] Receio de desentendimento com vizinhos
- [ ] Nada me deixaria inseguro
- [ ] Outro: ______

**7. Qual é o sistema do seu celular?** *(múltipla escolha)*

- ( ) Android
- ( ) iPhone (iOS)
- ( ) Outro / não sei

**8. Qual é a sua faixa etária?** *(múltipla escolha)*

- ( ) 18 a 29 anos
- ( ) 30 a 49 anos
- ( ) 50 a 64 anos
- ( ) 65 anos ou mais

## Seção final (depois da pergunta 8)
